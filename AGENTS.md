## Commands
- `npm run dev` — start Vite dev server
- `npx tsc --noEmit` — typecheck only (no emit)
- `npm run build` — typecheck + vite build to `dist/`
- `npx tsx scripts/generateAllAssets.ts` — regenerate procedural tile/item/building PNGs into `public/assets/`

## Architecture
- **3D voxel-style farming sim** using Three.js (PerspectiveCamera, not isometric)
- Entry point: `src/main.ts` → `Game` class owns the entire loop
- All 3D meshes are **procedurally generated** in `src/core/MeshFactory.ts` (no external model files)
- Textures are generated at runtime via canvas noise in `MeshFactory.getTileTexture()`
- Static PNG assets in `public/assets/` are generated by `scripts/generateAllAssets.ts` (used for legacy sprite fallbacks and mine items)

## Key Modules
| Directory | Purpose |
|-----------|---------|
| `src/core/MeshFactory.ts` | All 3D mesh builders (player, NPC, trees, buildings, crops, tools, items) + color palette |
| `src/core/SoundManager.ts` | Procedural Web Audio API synth — zero external audio files |
| `src/data/gameData.ts` | Crops, tools, mine items, material items, config constants |
| `src/farm/FarmGrid.ts` | Tile map, collision grid (`isSolid()`), crop lifecycle, shipping bin |
| `src/player/PlayerState.ts` | Inventory, stamina, gold/debt, save/load. Starts with all 4 tools + seeds |
| `src/mine/MineSystem.ts` | Mine floors, digging, bouncing item physics |
| `src/npcs/DialogueSystem.ts` | Typewriter dialogue with choices |
| `src/ui/UIManager.ts` | HUD, inventory bar, tooltips, shop panel |

## Critical Conventions
- **Tools are inventory items**: hoe, water, pickaxe, axe must be selected in hotbar before use (Space to act)
- **Action dispatch is tool-based**: `main.ts handleActions()` checks `sel.id` to determine action — always add new tool actions there
- **Collision uses axis-separated checking** in `handleMovement()` for smooth wall sliding
- **Shipping bin** (`B` key): drops held sellable items → wobble anim → morning buyer NPC walks to bin next sleep cycle
- **Crop spoilage**: unwatered crops die overnight; `FarmGrid.advanceDay()` returns spoiled list
- **`FarmTile.objGroup` is typed `THREE.Object3D`** (not Group) because some tiles use Mesh directly
- **Sound init requires user gesture**: `sound.init()` called on start button click only

## Gotchas
- `GAME_CONFIG` uses `startingDebt` / `startingGold` (not `startDebt`)
- Inventory is fixed 8 slots; `PlayerState` constructor pre-fills tools + seeds
- Mine system still uses sprite-based rendering (legacy) while farm is full 3D meshes
- `createSprite()` in AssetLoader kept only for mine compatibility
- Vite base is `./` for relative asset paths in production builds
- No test suite exists; verify with `npx tsc --noEmit && npx vite build`
